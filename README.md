# This project is now Council News Wire

The code that collects news from every Australian council and publishes it as
Bluesky feeds and RSS has moved:

**https://github.com/jonathonmarsden/council-news-wire**

The service itself is at **https://councilnewswire.au**.

If you're from a council checking what the crawler does, the new repository's
README and SECURITY.md describe exactly how it behaves, and its contact page is
https://councilnewswire.au/bot.html.
